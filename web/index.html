先在“工具接入”中连接工具，再在模板或实例选择来源。Agent 只连接上下文服务，获取输入并提交调用，服务负责发现与执行工具。
工具统一接入 → 模板 / 实例选择 → 服务编译与执行 → Agent 调用模型
1. 在服务端添加工具来源，再选择到模板或实例
2. 获取模型输入，服务端确认工具可用性
model_input 是任意 Agent 共用的消息与工具表示。工具连接、发现和执行由服务端负责；Agent 不需要 MCP 配置或工具执行器。ready=true 时保存 preparation_id，并把消息和工具交给模型。
3. 记录助手响应，将工具调用提交给服务执行
先用 message.append 保存模型实际返回的助手消息和 tool_call_ids，再把返回的 update.seq 作为 assistant_seq。服务自动记录工具调用与结果，Agent 重新 prepare 后继续推理。
